Three tools for Shopify and Klaviyo stores. They run in this page, so your exports never leave your computer.

Open the tools

Loading the analysis engine (about 10 seconds the first time)

Run them on your own exports

Each tool reads the file as your platform exports it. The example buttons load sample data, so you can see the output before using your own.

Check a template before it goes live

Paste the HTML from Klaviyo's code editor. It flags what a recipient would notice: a greeting that reads “Ciao ,”, a dead link, a hand-typed UTM that breaks the naming rules, a missing unsubscribe link, a subject cut off on a phone.

Lifecycle stages, behind a consent gate

From the Shopify orders export (Orders > Export, as it comes) and the consent export of your sign-up form or ESP. Every customer gets a stage: New, Repeat, At risk, Dormant or Churned. Only consent with a recorded source and date passes; everyone else goes to a suppression list with the reason.

When to send the second-order email

From the same orders export: how many customers buy again by day 30, 60, 90, 180 and 365, counting only customers who had a full year to come back. The median is the delay to set in the post-purchase flow.

The flows these emails belong to

Built in Klaviyo for a test store: a welcome series after the double opt-in, an abandoned cart, and a win-back for the customers the lifecycle tool marks At risk.

This page runs the repository's own Python in your browser with Pyodide: the same functions and tests as the command line. Nothing is sent to Klaviyo from here; writing to Klaviyo is a command-line step with an API key. Example files are handwritten with example.com addresses; the timing example uses the public UCI Online Retail orders.
